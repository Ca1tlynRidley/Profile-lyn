# PROFILE-lyn browser editor

Open `dist/index.html` directly, or serve the static `dist/` folder with any static file host. Normal editing needs no Node installation. Use `node --test test.cjs` for its logic tests.

Drafts stay in browser local storage. Export generates a JSON layout or a `ps1:` import command for the Minecraft server. The browser does not directly connect to the Minecraft economy; preview values are samples.

Private Sites repository/hosting metadata is intentionally absent from this GitHub source export. Hosting this editor is independent of building the Java mod. The default hosted URL's access is controlled by its owner; the offline editor remains available.

Minecraft item preview textures are Mojang/Microsoft assets, excluded from the original code's MIT license. Some special/block model previews differ from the in-game render.
