# PROFILE-lyn

A profile menu mod for Minecraft Java 26.2 using Fabric. It displays player information, with optional ECO-API-lyn integration for balances.

## Requirements


- Fabric Loader 0.20.1 or newer
- Fabric API for Minecraft 26.2

## Compatibility

- ECO-API-lyn-1.0.0

Install PROFILE-lyn 1.0.0 on the dedicated server only. 

Without ECO, the profile menu still works and the {money} placeholder shows "Unavailable". The default balance and leaderboard buttons need an economy mod that supplies /balance and /baltop; missing commands show an unavailable message. Custom menu commands keep the player's normal permissions.

## Usage

- /profile 
- /profile editor 
- /profile reload 
- /profile import 

The layout file is config/profile-lyn/profile.json. The mod includes the complete local browser editor and creates config/profile-lyn/editor/ plus config/profile-lyn/profile-editor.zip automatically when the server starts. No website hosting, account, extra port or Internet connection is needed to edit your menu.

## Download and open the editor

[Download PROFILE-lyn editor 1.0.0](https://github.com/Ca1tlynRidley/Profile-lyn/raw/refs/heads/main/PROFILE-lyn-editor-1.0.0.zip)

The complete editor is inside **PROFILE-lyn-editor-1.0.0.zip** in this repository. You only need this ZIP to edit a menu; you do not need to download the entire project source or install the mod on your PC.

1. Download `PROFILE-lyn-editor-1.0.0.zip` using the link above.
2. Extract the ZIP into a normal folder. On Windows, right-click it and choose **Extract All**.
3. Open the extracted `editor` folder, then double-click **index.html**. Your normal browser opens the editor locally.
4. Keep the entire editor folder together, including its scripts, styles and icons. Do not open index.html directly inside the ZIP or download that HTML file by itself.
5. Start with the default template, or click **Clear** to build your own menu. To edit an existing server layout, click **Import JSON** and select a copy of that server's `config/profile-lyn/profile.json`.
6. Arrange your items, names, hover text and actions, then click **Export to server → Copy import command**.
7. Run the copied `/profile import ...` command in Minecraft chat as an operator. In the server console, remove the leading `/` and run `profile import ...`.
8. Open `/profile` to see your saved layout. Editing the browser preview alone does not change the server.

No website publishing, sign-in, extra port or Internet connection is needed after downloading and extracting the ZIP. A `file:///` address in your browser is expected. The GitHub ZIP starts with the default template and does not automatically connect to your server.

## Editor files generated by your server

You can also use the editor copy included in the mod instead of downloading it from GitHub:

1. Start your dedicated server with PROFILE-lyn and Fabric API installed.
2. Join as an operator and run `/profile editor`. The command refreshes the editor's snapshot of the current server layout and shows opening instructions in chat.
3. If the server runs on your PC, open `config/profile-lyn/editor/index.html` from that server's folder. You can click **Copy editor file path** in chat and paste it into File Explorer's address bar.
4. If the server is hosted elsewhere, download `config/profile-lyn/profile-editor.zip` using its file manager or SFTP. Extract it on your PC, then open `editor/index.html`.

This server-generated ZIP opens a snapshot of that server's layout. Keep all the extracted files together and use the export/import steps above to apply edits.

For the JSON route, download profile.json from the editor, replace `config/profile-lyn/profile.json` on the server, and run `/profile reload`. Large layouts use this route.

Any server owner can use this workflow. A server-side mod cannot open a browser on another player's PC or transfer files to that PC automatically; `/profile editor` gives the operator the file location and instructions. Run it again and download a fresh ZIP when you want a snapshot of a changed server layout. See [the local editor guide](docs/LOCAL-EDITOR.md) for troubleshooting.

Names and descriptions support Minecraft color codes and placeholders such as {player}, {money}, and {level}. Menu actions can display a message, run a player command, refresh the menu, or close it.

After editing your profile locally, export and copy the complete import command. In the server console, paste it without the leading slash.
