# Using the local PROFILE-lyn editor

The complete editor ships inside PROFILE-lyn-1.0.0.jar. Every server that installs the mod gets its own copy automatically on startup. It does not connect to ChatGPT, publish a website, require an account, or open an HTTP port. ECO-API-lyn remains optional.

## Download the standalone editor from GitHub

You can use the editor without downloading the project source or getting files from a server. Download [PROFILE-lyn-editor-1.0.0.zip](https://github.com/Ca1tlynRidley/Profile-lyn/raw/refs/heads/main/PROFILE-lyn-editor-1.0.0.zip), extract the ZIP, and open `editor/index.html` in your browser. Keep the whole extracted folder together, including its scripts, styles and icons.

The GitHub download starts with the default template. Click Import JSON and choose a copy of your server's config/profile-lyn/profile.json to edit an existing layout. The editor runs locally and does not automatically connect to your server. Apply changes using the export/import steps below.

## Alternatively, generate files on your server

1. Put PROFILE-lyn and Fabric API in your dedicated server's mods folder and start the server once.
2. Join the server as an operator and type `/profile editor` in Minecraft chat.
3. The command refreshes the editor's layout snapshot and tells you where the files are. It also creates a ready-to-download ZIP.

The server now contains:

```text
config/profile-lyn/
  profile.json                 Running server layout
  profile-editor.zip           Download this for a hosted server
  editor/
    index.html                 Open this in your browser
    OPEN-EDITOR.txt             Quick instructions
    server-layout.js           Snapshot of the server layout
    app.js, core.js, ...        Required editor files
    icons/                     Required Minecraft item previews
```

## If the server runs on your own PC

1. Open your Minecraft server folder in File Explorer.
2. Open `config`, then `profile-lyn`, then `editor`.
3. Double-click `index.html`, or right-click it and choose your browser under Open with.
4. Alternatively, click **Copy editor file path** in Minecraft chat, paste that path into File Explorer's address bar, and press Enter. This path belongs to the computer running the server.

## If the server is hosted elsewhere

1. Open your hosting panel's server file manager, or connect using SFTP.
2. Go to `config/profile-lyn/` and download `profile-editor.zip` to your PC.
3. Extract the ZIP into a normal folder. On Windows, right-click it and choose Extract All.
4. Open the extracted `editor` folder and double-click `index.html`.

Keep the entire extracted folder together. Do not open the HTML directly inside the ZIP. Downloading only index.html leaves out its scripts, styles, icons and current layout. You may download the entire editor folder instead of the ZIP.

## Edit and apply your profile

1. Use the item library to place vanilla Minecraft items into the inventory grid. Clear starts an empty menu; Template restores the starter menu.
2. Select an item to edit its name, hover text, amount, glow and click action.
3. Choose Export to server, then Copy import command.
4. Paste the copied `/profile import ps1:...` command into Minecraft chat while you are an operator. In the server console, omit the leading slash: `profile import ps1:...`.
5. Run `/profile` to view your saved menu. Importing also saves a profile.json.bak backup of the previous layout.

For a large layout or the file route, choose Download profile.json, upload that file as `config/profile-lyn/profile.json` on the server, then run `/profile reload` in-game or `profile reload` in the console.

The browser is a preview. It does not send changes to your server automatically. Exporting and running the import command, or uploading JSON and reloading, applies your changes.

## Troubleshooting

- **ChatGPT sign-in appears:** You are using the old hosted link. Use the editor files generated by the current JAR instead.
- **The page is blank or item icons are missing:** Extract and keep all files together, including icons/. Opening index.html alone is not enough.
- **Your browser shows file:///:** This is expected; the editor is running from your own PC.
- **An older draft reappears:** Browser drafts are saved for the same folder and layout snapshot. Use Import JSON to load the desired profile.json, or run /profile editor and download a fresh ZIP after changing the server layout.
- **You changed the server layout:** Run /profile editor again before downloading the ZIP so the editor opens that new snapshot.
- **Cannot write editor files:** Check that the server process can write to config/profile-lyn/. The mod logs the error and the operator can retry /profile editor after fixing permissions.
- **ECO is absent:** The menu still works; {money} shows Unavailable. Remove or customize economy buttons if desired.

A server-side mod cannot automatically open files or a browser on another computer. For remote hosting, the operator downloads the generated ZIP and opens it locally. Players using /profile never need these editor files or a client mod.
